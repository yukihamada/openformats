検証ツール

作品 JSON と本体ファイル（音源・画像など）をドロップするだけで、指紋（SHA-256）・署名（Ed25519）・履歴チェーンが正しいかを、このブラウザ内で確かめます。ファイルはどこにも送信しません。

かんたんに言うと：作品と本体が「すり替わっていないか」を、その場で照合する道具です。コマンド python3 tools/of.py verify と同じ判定をブラウザで行います。

入力

作品 JSON と本体ファイルをドロップ または クリックして選択
JSON は 1 つ、本体ファイルは複数まとめて選べます（例: hitotsu-saki-e.music.json と take1_full.m4a）。JSON だけでも指紋・署名・履歴は検証できます。
または JSON を貼り付け：
JSON 待ち

検証結果

    まだ検証していません。上の欄に作品 JSON（と本体ファイル）を入れて「検証する」を押してください。

    何を見ているか

    1. 基本構造 — spec_version / kind / id が仕様どおりか。
    2. content_hash（作品の指紋） — 保存された指紋と、いま再計算した指紋が一致するか。一致すれば中身は改ざんされていません。
    3. renditions（本体ファイル） — 音源や画像の実ファイルの SHA-256 が JSON の記録と一致するか。
    4. 署名（Ed25519） — 指紋に対する作者の署名が有効か。
    5. hash_chain / revisions（履歴） — 改訂の連鎖が途切れていないか、差分が本体と整合するか。

    同じ判定はコマンドでも行えます：python3 tools/of.py verify <file>。このツールはその忠実な移植で、works/ の全作品で判定が一致することをテスト済みです（tests/verify.test.mjs）。

    openformats は MIT 公開の個人仕様です。このツールは検証をすべてブラウザ内で行い、ファイルを外部へ送信しません（このページ自体は初回に読み込む必要があります）。
