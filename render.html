メディア作成

設計図（作品 JSON）1つから、音声・画像・動画・PDF を、ボタン1つで作れます。曲もラジオも本も動画も、同じ操作。インストール不要、ファイルはどこにも送信しません。

これが便利なところ

① 1つの設計図から、いくつもの「実物」

曲のメタ・歌詞・台本・章が入った JSON ひとつで、試聴用の音声、サムネ用の画像、SNS 用の短い動画、配布用の PDF をまとめて作れます。元データを直せば、作り直すだけ。

② ブラウザだけで完結・送信なし

インストールもログインも不要。ファイルは外部へ送らず、この端末の中だけで生成します。機密の原稿や音源でも安心して試せます。

③ 種類を問わず、同じ操作

music・radio・book・movie など、どの作品でも同じ画面で同じボタン。形式ごとに別ツールを覚える必要がありません。

④ そのまま使えるファイルで保存

WAV・PNG・WebM・PDF は一般的な形式なので、そのまま再生・投稿・印刷に使えます。プレビューで確認してからダウンロード。

正直な範囲：このページの音声はブラウザ合成のプレビュー音源（メロディ確認用）です。本物の声（ナレーション・ポッドキャスト）は、同じ作品 JSON をコマンドの KOE / teai レンダラで音声化します。動画は簡易版で、ラジオは話者・章・現在の台本を表示しますが、本格的な編集は tools/render.py 側で行います。

使い方（3ステップ）

  1. 作品 JSON をドロップするか貼り付けます（ブラウザで作るで自作できます）。
  2. 作りたい形式のボタン（音声・画像・動画・PDF）を押すと、その場で作成します。
  3. プレビューを確認して「ダウンロード」で保存します。

たとえば、こんなふうに使えます

  • 曲（music） — 歌詞と構成から試聴用の音声と、サムネ用の画像を作る。
  • ラジオ／ポッドキャスト（radio） — 台本の確認用に、まず短い動画で流れを眺める。
  • 本・記事（book / article） — 原稿から配布用の PDF をすぐ書き出す。
  • 動画（movie） — 場面構成からタイトルカードの動画を試作する。

同じことをコマンドでも行えます：python3 tools/render.py <work.json> --kind audio --format wav --dry-run（プレビュー）／本物の声は --renderer koe --kind audio --format mp3。このページの音声はブラウザ合成のプレビューです。

本物の声で仕上げる（KOE に声を登録）

このページの音声は確認用のプレビューです。ナレーションやポッドキャストを自分の声で作るには、先に KOE へ声を登録します。登録は本人が録音し、利用への同意を行います。

  1. KOE の声登録ページを開き、案内に沿って自分の声を録音します。
  2. 録音を聞き直し、利用への同意を確認して登録を完了します。
  3. 登録した声は、作品 JSON を --renderer koe で音声化するときに使えます。

登録・録音・同意は本人が行ってください。このページや第三者が代わりに登録することはできません。声の利用範囲は KOE の案内に従います。
