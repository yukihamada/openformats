一括インポート

手持ちの音源・画像・動画などをまとめて選ぶだけで、1 ファイル = 1 作品の openformats JSON を一度に作ります。指紋（SHA-256）と content_hash を自動で入れるので、そのまま 検証ツール で合格する形になります。ファイルはどこにも送信しません。

入力

作品にしたいファイルをドロップ または クリックして選択
複数まとめて選べます。フォルダごと選ぶこともできます。種類（kind）は拡張子から自動で判定し、あとで変更できます。

作る作品（0 件）

まだファイルがありません。上の欄にファイルをドロップしてください。

ファイル種類タイトル
ブラウザの設定によっては、複数ファイルの保存確認が出ます。

使い方

  1. 作品にしたいファイルをまとめて選びます（フォルダごとでも可）。
  2. 作者名・ライセンスを入れると、全作品に反映されます。種類とタイトルは必要なら直せます。
  3. 「JSON をまとめてダウンロード」で保存し、本体ファイルと同じフォルダに置きます。
  4. 検証ツール に JSON と本体を入れると、指紋が一致して「合格」になります。

コマンドで同じことをする場合：python3 tools/of.py hash <file> --write で指紋を書き込み、python3 tools/of.py verify <file> で照合できます。このツールの出力はその形に合わせています。

openformats は MIT 公開の個人仕様です。このツールはすべてブラウザ内で処理し、ファイルを外部へ送信しません（このページ自体は初回に読み込む必要があります）。
