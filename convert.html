変換ツール

openformats の作品 JSON を、schema.org（検索エンジンや他アプリが作品情報を読める共通の書き方）や C2PA（誰が・いつ・どう作ったかの証明書）へ変換します。schema.org から作品 JSON への逆変換もできます。すべてこのブラウザ内で完結し、ファイルはどこにも送信しません。

かんたんに言うと：作品の設計図（JSON）を、他の世界が読める形に翻訳する道具です。content_hash は作品の「指紋」、JSON-LD は JSON で書く機械向けの意味づけ、と考えてください。

※ C2PA への変換はマニフェスト JSON の書き出しまでです。バイナリへの埋め込み（JUMBF/COSE 署名）は未実装です。

使い方

  1. 作品 JSON をドロップするか貼り付けます（ブラウザで作るで自作できます）。
  2. 形式タブを選ぶと、その場で変換されます。
  3. 「ダウンロード」で保存。schema.org は Web サイトの <script type="application/ld+json"> に貼れます。

同じ変換はコマンドでも行えます：python3 tools/export.py schema.org <file> / c2pa / markdown / csv / musicxml / otio / import。このツールはその忠実な移植で、出力は全サンプルで一致することをテスト済みです。

openformats は MIT 公開の個人仕様です。このツールは変換をすべてブラウザ内で行い、ファイルを外部へ送信しません（このページ自体は初回に読み込む必要があります）。
